# Student Dashboard (SIS 4)

Проект разделен на клиентскую часть (Vue 3 + Ant Design Vue + Tailwind CSS) и серверную часть (Nest.js).

## Структура проекта

- `/client` — фронтенд на Vue 3
- `/backend` — бэкенд на Nest.js

## Запуск проекта

### 1. Запуск бэкенда (Nest.js)
```bash
cd backend
npm install
npm run start:dev
```
Сервер будет доступен по адресу: `http://localhost:3000` (API: `http://localhost:3000/api`)

### 2. Запуск фронтенда (Vue.js)
```bash
cd client
npm install
npm run dev
```
Клиент будет доступен по адресу: `http://localhost:5173`
